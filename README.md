《艾瑟蘭異界物語：新世界》玩家使用的**公開、免費、唯讀**查詢看板。此網站不是另一套遊戲系統，也不是官方存檔。

- [網站入口](https://fishertsou0429.github.io/aetheran-dashboard/)
- 資料庫：[data/latest.json](./data/latest.json)
- 正式資料基準：**第191日11:18，完整存檔 V119**，附《06》V13及《12》V63。
- 不把舊歷史快照的「當前」欄位覆蓋最新正式劇情；不因本次JSON未列出某個物品、NPC、商品或任務就視為不存在。

## GitHub Pages 啟用

首次請到儲存庫的 **Settings → Pages → Build and deployment → Deploy from a branch**，選 **main** 與 **/(root)**，按 **Save**。部署完成後開啟上面的網站入口。若GitHub Pages尚未啟用，網址可能暫時無法顯示。

## 看板同步約定（玩家第191日暫停設定）

同步有**兩個獨立的觸發條件**：

1. 每進行 **20個正式小說回合**，在該回合結束後嘗試將已確立的新劇情變更更新到GitHub。
2. **每次正式存檔成功後**，不論已過幾回合，都額外嘗試同步一次。正式「完整存檔」需按原規則成功上傳所有必要檔案至檔案庫才算成功；「增量存檔」以其正式完成條件為準。同步與正式存檔是兩個不同動作。

### 計數與失敗處理

- 看板同步使用獨立計數器「距離上次成功看板同步 X/20」；**不改變原本的25/50正式存檔計數器**。
- 正式小說回覆後計數 +1，規則討論、暫停、查核、建站與存檔操作不增加回合。
- 達20回合或完成正式存檔時，觸發的GitHub寫入**成功並重新核對**後，才將看板同步計數歸零，並寫入最新遊戲時間／來源存檔。
- 如GitHub寫入失敗、權限失效或檔案核對失敗，**保留同步待辦與原計數**，繼續在下一個可用回合重試；可以使用「更新看板」手動補同步。
- 如果同一次回合同時滿20與正式存檔成功，**合併成一次同步**，不重複計數或覆寫。
- **注意能力邊界**：ChatGPT無法在沒有收到訊息／沒有執行工具的情況下自行在背景監控對話或定期提交；「自動」指正式回合與存檔執行流程中的觸發檢查，不是GitHub Actions能自行讀懂聊天內容。
- 看板是只讀副本，**不會回傳資料給ChatGPT、不要求OpenAI API金鑰，也不會創造NPC事件或調整遊戲帳款**。

### 更新方式

1. 先讀取 **GitHub目前最新版本** 與 **最新有效正式存檔／後續已確立劇情**。
2. 按固定ID更新JSON記錄，保留未變動紀錄，區分「已發生、預計、待審、待驗收、未領款、待核對」。
3. 遵守NPC知識隔離：只能顯示澈已知或可供玩家查詢的正式歷史，不能把隱藏的未來主線／NPC秘密寫成已知。
4. GitHub每次成功提交會保留版本歷史；必要時可在 `data/history/` 增加基準紀錄。
5. 更新 `snapshot.gameDay`、`snapshot.gameTime`、`snapshot.officialSave`、`sync.turnsSinceSuccessfulSync` 等中繼資料，**只有成功提交後**才能宣告同步完成。
6. 網頁只把GitHub JSON顯示出來，所有日期都是**遊戲內日期**；同步時間和劇情時間需區分。
